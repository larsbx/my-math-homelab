# Domain adapters

Domain adapters bind shared oracle infrastructure to claims owned elsewhere. Initial stable domains are finite integer kernels, finite Mandelbrot, finite Julia sets, Pisot substitutions, multiplication fibers, thin groups, and height pairings.

Adapters must not redefine claims or issue acceptance verdicts. Domain fixtures remain in their owning repositories; this repository may mirror immutable vectors by digest.

The name `NLAP-JT` is intentionally not used as a durable domain identifier because that repository is being migrated. Salvageable material may be imported with explicit legacy provenance, but new bindings target stable claim and boundary identifiers.
