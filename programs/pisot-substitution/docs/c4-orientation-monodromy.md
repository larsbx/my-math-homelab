# C4-C orientation cocycle and the oriented double cover

**Status:** finite combinatorial construction and dichotomy proved. It does
**not** prove C4, C1, G1, or PSC.

The normalized balanced-pair automaton identifies `(u,v)` with `(v,u)`. That is
appropriate for reachability, but it forgets one bit of data needed for a
word-level derived substitution: after inflation and reduction, an irreducible
child may occur in the normalized orientation or with its two sides swapped.

This note restores that bit as a `Z/2` cocycle.

## 1. Signed child occurrences

Fix the canonical normalized representative

`T=(u_T,v_T)`

of every BPA state. For a parent `T`, factor the **raw** inflated pair

`(sigma(u_T), sigma(v_T))`

into irreducible raw children

`R_1 ... R_m`.

Let `U_i` be the normalized state underlying `R_i`. Define

`eps(T -> U_i) = +1` if `R_i=(u_{U_i},v_{U_i})`,

`eps(T -> U_i) = -1` if `R_i=(v_{U_i},u_{U_i})`.

Multiple occurrences are retained separately. The executable implementation is
`psc_research.orientation.oriented_children`.

If the parent orientation is swapped, every raw child orientation is swapped as
well. Thus if an oriented parent carries sign `o in {+1,-1}` relative to its
canonical representative, the child occurrence carries orientation

`o * eps(T -> U_i)`.

## 2. The gauge equation

Let `C` be a strict closed nonproductive recurrent SCC. A choice of a preferred
orientation for every normalized state is a function

`g:C -> {+1,-1}`.

The choice makes every child occurrence orientation-preserving exactly when

`g(U) = g(T) * eps(T -> U)`

for every signed child occurrence.

### Proposition 1 — cocycle triviality criterion

Such a gauge exists if and only if the product of edge signs around every
closed walk is `+1`.

### Proof

If a gauge exists, the signs telescope:

`prod eps(T_i -> T_{i+1}) = prod g(T_i)g(T_{i+1}) = +1`.

Conversely, choose a root orientation and propagate `g` along paths using the
gauge equation. Two paths to the same state give the same value precisely when
the sign product around the resulting closed walk is `+1`. QED.

The implementation `solve_orientation_gauge` solves these equations exactly.

## 3. Trivial-monodromy case: two word morphisms

Assume the cocycle is trivial and choose a gauge `g`. Reorient each state once:

- if `g(T)=+1`, keep `(u_T,v_T)`;
- if `g(T)=-1`, use `(v_T,u_T)`.

Write the resulting oriented words as `U(T)` and `V(T)`. Let `tau_C(T)` be the
ordered sequence of normalized child states in the reduction of `sigma(T)`.
The gauge equation says that every raw child occurs in exactly its chosen
orientation. Therefore the following are **word identities**, not only Parikh
identities:

` sigma(U(T)) = U(tau_C(T)) `,

` sigma(V(T)) = V(tau_C(T)) `.

Equivalently, as morphisms on the free monoid generated by `C`,

` sigma o U = U o tau_C `,

` sigma o V = V o tau_C `.

For every state `T`, `U(T)` and `V(T)` have the same Parikh vector, while
nonproductivity requires them to remain genuinely distinct and to produce no
coincidence factor.

Thus trivial orientation monodromy turns a hypothetical counterexample into two
distinct, Parikh-equal word realizations of the **same** irreducible derived
substitution `tau_C` intertwining with `sigma`.

## 4. Nontrivial-monodromy case: oriented double cover

When no gauge exists, replace the normalized alphabet `C` by

`C~ = C x {+1,-1}`.

For each signed occurrence `T -> U` with sign `eps`, define the lifted child
transition

`(T,o) -> (U, o*eps)`.

Doing this occurrence-by-occurrence in the original child order defines the
**oriented derived substitution** `tau~_C`.

There is a fixed-point-free deck involution

`J(T,o)=(T,-o)`.

Because child orientations are obtained by multiplication by `eps`,

`tau~_C o J = J o tau~_C`.

Define a single word realization `W` by

`W(T,+)=u_T`, `W(T,-)=v_T`.

Then the raw-factorization construction gives the word identity

` sigma o W = W o tau~_C `.

The second side is obtained by the deck involution: `W o J`.

### Proposition 2 — connectedness dichotomy

If the base child graph on `C` is strongly connected, then:

- trivial cocycle: the oriented double cover splits into two isomorphic
  components, corresponding to the two global gauges `g` and `-g`;
- nontrivial cocycle: the oriented double cover is strongly connected.

### Proof sketch

This is the standard two-sheet voltage-graph argument. Along a directed path,
the lift endpoint orientation is the start orientation multiplied by the path
sign. Strong connectivity gives paths between all base vertices. In the
trivial case every closed walk has positive sign, so the two gauge sections are
preserved. In the nontrivial case some closed directed walk has negative sign;
lifting it connects the two orientations above its base vertex, and strong
connectivity then connects both sheets over every vertex. QED.

## 5. Why this matters for C4

The normalized SCC alone hides a possible finite monodromy obstruction. The
remaining proof should therefore split explicitly:

### Case T — trivial orientation cocycle

There are two distinct Parikh-equal morphisms `U,V` with

` sigma U = U tau_C`, `sigma V = V tau_C`.

Potential eliminators:

1. unique decodability / recognizability of `sigma`;
2. the Parikh intertwiner `P_C N_C=M P_C`;
3. endpoint synchronization-quotient signatures;
4. show that two distinct realizations force a nontrivial fibre or symmetry
   incompatible with the Pisot contraction data.

### Case N — nontrivial orientation cocycle

There is a connected `Z/2` extension `tau~_C` with a commuting deck involution
and a word factor map `W` to `sigma`.

Potential eliminators:

1. show that the deck involution gives finite monodromy on the relevant
   geometric/MEF fibre;
2. constrain that monodromy with the irreducible Pisot stable contraction;
3. or show directly that a negative orientation cycle forces a synchronizing
   cut when combined with the endpoint quotient phases.

This makes the previously informal "finite monodromy" idea concrete: the first
monodromy group that actually appears at the normalized BPA level is exactly
`Z/2`.

## 6. Calibration

The repository's primitive non-Pisot negative control

`1 -> 2, 2 -> 123, 3 -> 2`

has a strict closed nonproductive two-state component

`A=(12,21)`, `B=(23,32)`.

Its signed reductions are

`A -> A^- B^+`,

`B -> A^+ B^-`.

In particular both states have a negative self-loop, so the orientation cocycle
is nontrivial. `tests/test_orientation.py` verifies this and checks that the
signed normalized children reconstruct the raw inflated words exactly.

The example lies outside the standing PIP regime; it is a calibration showing
that orientation monodromy is a real obstruction type and cannot simply be
assumed trivial.
