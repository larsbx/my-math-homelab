# P1-B joint-local census: bounded windows and a regular collision family

**Status:** exact finite-corpus evidence plus an elementary recurrence proposition. This note does **not** prove or disprove G1b-2.

## 1. Purpose

The joint-local layer keeps, for fixed source radius `r` and digit-window size `w`,

- relative source-index displacement;
- exact source prefix defect;
- selected source letters;
- radius-`r` source context on both sides;
- the first `w` and last `w` substitution digits on both sides.

It intentionally discards the middle of a long symbolic address. The new census asks what identifications this bounded projection actually makes on certified renewal cuts.

A projection collision is recorded as evidence to classify. A collision is **not automatically a mathematical obstruction**: it may be an undesirable information loss, or it may be a genuine recurrent pattern that should be represented by one finite automaton state.

## 2. Exact census discipline

`kernel/psc/joint_local_census.mojo` uses two independent checks:

1. materialize the requested finite inflation and stream the aligned Parikh-difference walk to enumerate interior zero returns;
2. pass every enumerated cut through the symbolic renewal-address constructor and joint-local projection.

The second layer must accept every oracle cut. No exception is swallowed as “not a return”; disagreement fails the run.

The census therefore remains finite and empirical, while each included observation is exactly certified.

## 3. Controlled determinant-2 corpus

Use

```text
τ(0) = 1
τ(1) = 021
τ(2) = 001
```

with `det M_τ = 2`, and the strict first-return seed

```text
s = (01,10).
```

Radius `r=2` already exposes the complete two-letter source words, with exterior sentinels. For depth caps `D=3,...,7`, the exact census gives:

| max depth `D` | certified cuts through `D` | window `D-2` collision pairs | window `D-1` collision pairs |
| ---: | ---: | ---: | ---: |
| 3 | 16 | 3 | 0 |
| 4 | 43 | 3 | 0 |
| 5 | 107 | 3 | 0 |
| 6 | 255 | 3 | 0 |
| 7 | 601 | 3 | 0 |

This table is deliberately a bounded-corpus statement. It does not justify choosing `w=6` globally.

## 4. The three persistent witnesses

Let

```text
U_d = τ^d(01),
V_d = τ^d(10),
L_d = |U_d| = |V_d|.
```

For `d >= 2`, both words end in `021`. Hence the three positions

```text
c_{d,j} = L_d - 3 + j,   j in {0,1,2},
```

are zero returns: the suffix removed from both sides is respectively `021`, `21`, or `1`.

At each of these cuts the source location is fixed:

- top: source index `1`, source letter `1`;
- bottom: source index `1`, source letter `0`;
- source defect: `(1,-1,0)`.

Consequently **every fixed source-context radius** gives the same source-context data at depths `d-1` and `d`.

## 5. Regular digit recurrence

Write

```text
a = (1,2),
b_j = (1,j),
c = (0,0).
```

The exact symbolic digit paths at `c_{d,j}` are

```text
top_d    = a^(d-1) b_j,
bottom_d = c a^(d-2) b_j.
```

Therefore, passing from depth `d-1` to `d` inserts exactly one additional copy of `a=(1,2)` on each side.

For a head/tail window of size `w <= d-2`, the extra copy lies outside the information needed to distinguish the two depths:

```text
head_w(top_{d-1})    = head_w(top_d),
tail_w(top_{d-1})    = tail_w(top_d),
head_w(bottom_{d-1}) = head_w(bottom_d),
tail_w(bottom_{d-1}) = tail_w(bottom_d).
```

Thus the bounded joint-local projections at the corresponding three cuts coincide, although the full relative addresses have different levels and different full digit strings.

This proves an elementary limitation of **raw bounded end windows as an injective encoding of full address observations**. It does **not** show that these two observations must be distinct states in a correct finite renewal quotient.

## 6. Positive interpretation: this family is regular

The important feature of the persistent collisions is not merely that they survive larger depths. They are generated by the regular language pattern

```text
a* b_j
```

on the top side and

```text
c a* b_j
```

on the bottom side.

A finite automaton can represent the repeated `a=(1,2)` block by a loop rather than by remembering an ever-growing middle word.

So the census changes the next target:

```text
bounded source context
+ finite automaton / recurrence class of the whole digit path
+ exact arithmetic coordinate when needed
```

rather than

```text
bounded source context
+ ever larger raw head/tail windows.
```

In the non-unimodular setting, a residue or profinite coordinate remains admissible if the finite recurrence class alone does not separate the remaining continuation behavior. The census does not assume in advance that such a coordinate is necessary.

## 7. Next experiment

Quotient the certified digit paths by explicitly recognized finite recurrence loops, beginning with the `(1,2)` loop above, and rerun the joint census.

For every residual collision retain:

- the two certified observations;
- their labelled source pairs;
- their complete symbolic addresses;
- the finite recurrence classes assigned to both paths;
- the smallest tested arithmetic refinement that separates them, if any.

The theorem-facing question is then whether all realizable renewal behavior factors through finitely many such recurrence/arithmetic classes—not whether a fixed raw digit window happens to be injective on a finite depth cutoff.
