# Penrose 2D ↔ PSC interface research bridge

**Status:** research bridge only; non-load-bearing for PSC theorem status.

This note records structural analogies between the current 2D Penrose pilot and named PSC research programs. It does **not** import Penrose conclusions into the PSC proof, and it does not change any claim status in the PSC ledger or roadmap.

## Why this exists

The 2D Penrose pilot is useful as a geometric laboratory for finite-state interface rigidity. The closest PSC analogies are not the current shortest PDS proof route itself, but the stronger parallel programs that retain ordered, labelled, and ancestry-sensitive data.

The live PSC roadmap remains authoritative for theorem status. In particular, issue #84 / Open Problem 5.35 remains the only open premise on the current shortest G1-free PDS route, while G1b-2 renewal finiteness and the realization/MEF bridge remain parallel open programs.

## Source/process firewall

The Penrose pilot distinguishes three classes of facts.

### Source-grounded
- five unoriented line-direction classes `D0,...,D4`;
- Robinson triangle prototiles `A,B`;
- substitution counts `A -> A+B`, `B -> A+2B`;
- substitution matrix `[[1,1],[1,2]]` with PF eigenvalue `phi^2`;
- frozen parent orientations;
- certified positive child-placement rows and parent-boundary partitions;
- original open items `G2D-1` through `G2D-4`.

### Mechanically derived in the pilot
- `Q_L(B2) = phi^2 + 1`;
- reflected `epsilon=-` rows;
- first oriented separator field `I_oriented_1`;
- process-level `I_side`;
- prefix-level continuation data for `I_oriented_2`.

These are derived project outputs, not source-verbatim statements.

### Still open in the Penrose pilot
- full continuation of `I_oriented_2`;
- rhomb↔triangle aggregation writeup `G2D-1`;
- strict-growth invariant `Phi` (`G2D-2`).

## Where the transfer is strongest

### P2 / G1b-2 renewal finiteness

The PSC roadmap asks for a uniform finite-return theorem for realizable labelled first returns. The Penrose pilot attacks the higher-dimensional analogue directly: keep the boundary/interface label, collar, side, orientation, and ancestry data until the residual interface type becomes finite or a strict-growth invariant excludes recurrence.

This is the strongest mathematical cross-pollination target.

### P4 realization / MEF bridge

The Penrose workflow forces a strict separation between:

1. a formal local interface state;
2. a locally legal patch;
3. a globally realizable tiling configuration.

That is exactly the realization firewall used in PSC. This is a direct methodological transfer even before any theorem transfers.

### P1b / strict zipper

Penrose separator/collar computations are useful intuition for ordered boundary persistence and boundary hitting. They are **not** a proof of the PSC strict-zipper gate: the non-unimodular PSC branch requires the full contracting representation, including finite-place coordinates when necessary.

## What must not be inferred

This bridge does not claim:

- that Penrose is an instance of the 1D PSC proof;
- that a Penrose separator theorem proves #139;
- that finite Penrose collar data proves a universal PSC return theorem;
- that geometric 2D acyclicity implies finite BPA in the PSC setting;
- that a process-derived Penrose field is source-grounded.

6. Feed back into PSC only theorem-shaped mechanisms tied to a named open gate.
