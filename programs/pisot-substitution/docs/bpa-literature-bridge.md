# Balanced-pair literature bridge to repository `B_sigma`

**Status:** repository-side definition bridge proved below; the final literature-to-G1 implication is deliberately separated into the exact seed-termination statement that must be supported by citation. No claim is imported by name alone.

## 1. Why this note exists

The current repository proof architecture treats

> **G1.** `B_sigma` is finite for every primitive irreducible Pisot substitution in the target regime

as an open hypothesis.

The balanced-pair literature is closer to this statement than the old ledger recorded. Akiyama–Barge–Berthé–Lee–Siegel, *On the Pisot Substitution Conjecture* (2015), Theorem 5.3, states for an irreducible Pisot substitution that pure discrete symbolic spectrum is equivalent to termination with coincidence of the balanced-pair algorithm, and adds that a seed of the form `(ij,ji)`, `i != j`, suffices for the criterion. The survey points to earlier balanced-pair work including Sirvent–Solomyak and generalized algorithms such as Martensen.

The phrase “balanced-pair algorithm” must nevertheless be matched to this repository's exact graph definition before a dependency ledger writes `PDS => G1`.

## 2. Repository definition

For an alphabet `A`, the Python reference implementation uses

```text
SeedRepo = { (ab,ba) : a<b in A }.
```

For a normalized balanced state `T=(u,v)`, one transition:

1. forms `(sigma(u),sigma(v))`;
2. cuts at every common Parikh-prefix return;
3. takes the resulting irreducible balanced factors;
4. normalizes each factor by identifying `(x,y)` with `(y,x)`;
5. enqueues unseen factors.

Coincidence states are terminal because they are already productive and need not be inflated further for the reachability/productivity questions in this repository.

Let `F_{a,b}` denote the normalized factor closure obtained by running exactly this operation from the single seed `(ab,ba)`.

Then, by breadth-first closure under the same child operation,

> **Repository union lemma**
>
> `Vert(B_sigma) = union_{a<b} F_{a,b}`
>
> up to the terminal coincidence convention.

### Proof

Every repository vertex is generated from one of the finitely many initial seeds by finitely many applications of the child operation, so it belongs to the corresponding single-seed closure. Conversely, every single-seed closure begins from a repository seed and uses the same child operation, so every one of its vertices is generated by the all-seed BFS. Taking the union gives equality. Making coincidence states terminal removes only descendants that are irrelevant after a coincidence has already been produced and cannot introduce new noncoincident vertices. QED.

Because the alphabet is finite, this immediately gives:

> **Finite-union corollary.** If every seed closure `F_{a,b}` is finite, then the repository `B_sigma` is finite.

Normalization by side swap cannot spoil finiteness: it is a quotient of the raw ordered-pair closure.

## 3. Literature-side statement actually needed

To deduce repository G1 from PDS using the finite-union corollary, it is enough to establish the following precise literature claim:

> For an irreducible Pisot substitution with PDS, the balanced-pair algorithm started from **each** seed `(ij,ji)` terminates with coincidence, hence has only finitely many irreducible factors.

If the “any particular seed” clause of Theorem 5.3 is an equivalence for every chosen seed, this statement follows immediately. If that clause is only a one-way sufficiency criterion (“termination from one selected seed implies PDS”), then PDS does not automatically give finiteness of every seed closure and an additional reachability/equivalence argument is required.

This distinction is the entire remaining literature bridge. It should be checked in the theorem's proof or in the cited generalized-balanced-pair source rather than inferred from the word “any.”

If the final seedwise implication is confirmed, G1 is a necessary consequence of PDS for the repository graph, so `G1 + C1 => PDS` is not merely an arbitrary sufficient route: G1 is itself part of what any proof of PDS must ultimately account for.
