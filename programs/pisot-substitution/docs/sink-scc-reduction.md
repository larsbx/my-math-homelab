# Sink-SCC reduction for SCC Producer

**Status:** proved finite graph reduction; does **not** prove G1, C1, C2, C3, or PSC.

This note removes an unnecessary universal burden from the boundary-synchronization program. To prove SCC Producer in a finite balanced-pair automaton, it is not necessary to force synchronization inside every recurrent noncoincident SCC. It is enough to rule out a closed nonproductive sink SCC.

## 1. Setup

Let `B` be a finite directed balanced-pair automaton. A state is **productive** if some directed path from it reaches a coincidence state. Let

`NP = { v : no coincidence state is reachable from v }`

be the nonproductive set.

A recurrent SCC means an SCC containing a directed cycle. A noncoincident SCC contains no coincidence state.

## 2. Forward closure of nonproductivity

### Lemma 1

`NP` is forward-closed: if `v in NP` and `v -> w`, then `w in NP`.

### Proof

If `w` were productive, there would be a path from `w` to a coincidence state. Prepending the edge `v -> w` would give a path from `v` to a coincidence state, contradicting `v in NP`. QED.

## 3. Existence of a sink counterexample SCC

### Lemma 2

If `NP` is nonempty, then the induced subgraph `B[NP]` contains a sink SCC `C` in its condensation DAG.

### Proof

`B[NP]` is a finite nonempty directed graph. Its condensation graph is a finite DAG, and every finite nonempty DAG has a sink vertex. The corresponding SCC is `C`. QED.

### Lemma 3

Such a sink SCC `C` is closed in the full automaton `B`.

### Proof

Take `v in C` and an edge `v -> w` in `B`. By Lemma 1, `w in NP`. Since `C` is a sink SCC of the condensation of `B[NP]`, `w` cannot lie in a different SCC of `B[NP]`. Therefore `w in C`. QED.

### Lemma 4

`C` is recurrent, noncoincident, and nonproductive.

### Proof

Every state of `C` lies in `NP`, so `C` is nonproductive and contains no coincidence state. A finite closed SCC has at least one outgoing edge from each balanced-pair state generated by inflation/decomposition; following edges indefinitely inside the finite SCC yields a directed cycle. Hence `C` is recurrent. QED.

## 4. Sink-SCC reduction theorem

### Theorem

For a finite balanced-pair automaton `B`, the following are equivalent:

1. every state of `B` is productive;
2. there is no closed nonproductive recurrent noncoincident SCC;
3. there is no sink SCC of the nonproductive induced subgraph.

### Proof

`1 -> 2` and `1 -> 3` are immediate because the nonproductive set is empty. `3 -> 1` follows from Lemma 2: if a nonproductive state existed, a sink SCC of `B[NP]` would exist. `2 -> 1` follows from Lemmas 2--4: any nonempty `NP` would contain a closed nonproductive recurrent noncoincident SCC. QED.

## 5. Consequence for the boundary route

Suppose G1 holds, so `B_sigma` is finite. To prove SCC Producer it is enough to show that a closed nonproductive recurrent noncoincident SCC cannot exist.

The Boundary Synchronization Lemma gives a contradiction as soon as one zero-return boundary in such an SCC has a synchronizing adjacent endpoint pair. Therefore the boundary program only needs the following target:

> **Sink-SCC boundary escape.** Every hypothetical closed nonproductive recurrent noncoincident PIP SCC contains a synchronizing zero-return boundary.

There is no need to prove that every recurrent SCC synchronizes. An SCC may fail the local boundary test and still have an outgoing noncoincident edge leading, through later SCCs, to productivity.

## 6. Interaction with newborn-cut locality

`docs/c3-locality-reduction.md` proves that any higher-inflation newborn synchronizing cut localizes to a one-step newborn cut of an irreducible balanced block from the previous level.

Inside a closed nonproductive SCC, every such noncoincident block stays in the same SCC. Hence the sink-SCC boundary target reduces further to:

> **C3-local.** In every hypothetical closed nonproductive recurrent noncoincident PIP SCC `C`, some state `T in C` has a one-step interior zero-return cut in `sigma(T)` whose adjacent endpoint pair synchronizes.

Thus two independent reductions are now proved:

1. **graph reduction:** arbitrary nonproductivity -> a closed sink SCC;
2. **lineage reduction:** arbitrary newborn horizon -> a one-step newborn cut in a state of that SCC.

The remaining open step is an existence theorem on one finite recurrent SCC.

## 7. Exact corpus calibration

The exact Mojo census over all 4554 alphabet-3 PIP substitutions with image lengths `<= 3` finds 5022 recurrent noncoincident SCCs. Of these, 60 have neither inherited nor newborn synchronization in the one-step local test.

The exception audit shows:

- all 60 are singleton SCCs;
- 0 has a direct coincidence child;
- all 60 have a noncoincident exit;
- 0 is closed with no direct coincidence.

Therefore every local boundary-test failure in this finite corpus lies outside the sink/closed counterexample class. Equivalently, every recurrent noncoincident SCC in the corpus that is closed against noncoincident escape is caught by the boundary mechanism or is already productive by another route.

This is finite evidence only. The theorem above is the graph reduction; the PIP-specific existence theorem C3-local remains open.

## 8. Next proof obligation

Assume, for contradiction, that `C` is a closed nonproductive recurrent noncoincident SCC for a primitive irreducible Pisot substitution and that every one-step interior zero-return boundary from every `T in C` has adjacent endpoint pairs trapped in the nonsynchronizing cores `NSync_+` and `NSync_-`.

The next target is to combine:

- finiteness/recurrence of state and endpoint types inside `C`;
- primitivity of the substitution;
- Pisot contraction in the stable directions;
- the common-cut recurrence machinery;

and derive a contradiction. This is the sharpened C4 route.
