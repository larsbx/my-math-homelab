# Literature gate — Tier 2 recurrent loop-gain diagnostic

## Proposed step

PR #152 opens the Tier 2 Growth Bridge with a new theorem-facing diagnostic
(`docs/tier2-growth-bridge.md`, `docs/tier2-penrose-phi-cocycle.md`):

1. export each recurrent component of a finite packet quotient as a fixture
   carrying an exact additive edge cocycle `DeltaPhi : Edge -> Gamma`;
2. compute the loop-gain subgroup `G_q = < sum_{e in ell} DeltaPhi(e) >`
   over closed loops `ell` at `q`;
3. prove an eigenvalue-to-kernel bridge — a measurable eigenvalue imposes
   annihilation constraints on `G_q` — then an inflation-closure lemma
   upgrading `G_q` to the `Z[lambda]`-module it generates, then a finite
   residual resonance test on the quotient (for Penrose, the index-11
   quotient `Z[phi] / (4 - phi)`);
4. the first executables: the `affine_forcing` adapter
   (`kernel/psc/tier2_loop_gain_fixture.mojo`), the Penrose `H_tail`
   `penrose_phi_increment` channel (`kernel/psc/penrose_phi_tail.mojo`), and
   the fixture schema `schemas/tier2-loop-gain-fixture.schema.json`.

The review asks whether steps 2–3 duplicate a known construction and whether
the hypotheses of the imported spectral theory actually reach the fixtures.

## Decision

**Redirect, then proceed with a narrowed target.**

- The finite machinery (occurrence-labelled fixtures, exact cycle gains,
  generated module) proceeds. Its novelty is restricted to exact,
  fail-closed, occurrence-preserving certificates for the repository's
  packet quotients; the objects themselves are standard.
- Obligation 3 (eigenvalue-to-kernel) is **imported, not reproved**:
  it is Solomyak's return-vector criterion.[^1][^2]
- Obligation 5 (inflation closure) is **automatic** in the asymptotic form
  of that criterion and **degenerate** in the exact-annihilation form
  written in the PR (Findings 2–3).
- Obligation 6 (finite residual resonance mod 11) is **stopped** as posed.
  It is replaced by the Pisot trace-integrality test on the module spanned
  by *all* return vectors, where the tail index 11 plays no role
  (Finding 4, negative control C2).
- The `affine_forcing` channel must not be fed to a plain-sum cycle kernel as
  if it were an untwisted cocycle (Finding 5); its loop invariant is the
  `beta`-twisted sum.

The narrowed Tier 2 question that survives the review is:

> **Recurrent visibility.** Does the `Z[lambda]`-module generated by the
> loop gains of the recurrent packet quotient equal the `Z[lambda]`-module
> generated by the full return set `Xi`? If yes, the recurrent quotient is a
> finite certificate for Solomyak's condition; if not, the defect module is
> the new finite invariant.

This is a finite, checkable statement about the repository's own quotients;
no spectral conclusion is claimed from it until it is proved.

## Findings

### 1. Loop gains of an edge cocycle are standard graph/tiling cohomology

"A nonzero loop gain forbids a single-valued state potential" is the
statement that an edge cocycle on a finite graph is a coboundary iff it
vanishes on the cycle space `H_1`; `G_q` is the image of `H_1` of the
component under the cocycle. In tiling language, such cocycles over the
Anderson–Putnam / packet complex are classes in `H^1` of the hull, and
Kellendonk–Sadun identify topological eigenvalues with the asymptotically
negligible part of `H^1`, following Clark–Sadun's shape deformations.[^3]
Tier 2 documents should use this terminology (edge cocycle, coboundary,
`H^1` class, periods) and claim no novelty for `G_q` itself.

### 2. The eigenvalue-to-kernel bridge is Solomyak's theorem

For a primitive tile substitution of finite local complexity with expansion
`phi` and a fixed point, the following are equivalent for `alpha in R^d`
(Solomyak, *Eigenfunctions for substitution tiling systems*, Thm 3.13;
*Tilings and dynamics*, Thm 5.4; originally *Dynamics of self-similar
tilings*, 1997):[^1][^2]

1. `alpha` is a topological eigenvalue;
2. `alpha` is a measurable eigenvalue;
3. `lim_n exp(2 pi i <phi^n z, alpha>) = 1` for every return vector
   `z in Xi` (translations between tiles of the same type), and
   `exp(2 pi i <g, alpha>) = 1` for every period `g`.

So "measurable" in obligation 3 buys nothing over "continuous", and the
bridge from eigenvalue to loop data is exactly condition (3) with
`Xi` in place of `G_q`. The symbolic analogue — eigenvalues of a primitive
substitution via lengths of `sigma^n` applied to return words — is Host
(1986) and Ferenczi–Mauduit–Nogueira (1996).[^4] Both are *asymptotic*
conditions, not exact annihilation.

**Transfers:** primitivity, FLC, self-similarity (`phi = theta I`) for the
Penrose and one-dimensional PIP settings.
**Does not transfer automatically:** that loop gains of *one recurrent
component* exhaust `Xi`. Return vectors are displacements between *any* two
tiles of the same type; `G_q` is a subgroup of their span, possibly proper.
That gap is the narrowed target above.

### 3. Inflation closure is built in; its exact form is degenerate

Condition (3) is invariant under `z -> phi z` by reindexing `n`, so the set
of `z` satisfying it is a `Z[theta]`-module: it is closed under sums and
under `z -> theta z`. Checking the condition on generators of `Xi`
therefore already checks the full `Z[theta]`-module they span. No separate
lemma is needed for the asymptotic form.

The PR's exact form — "a measurable eigencharacter must annihilate the whole
principal submodule `Z[phi] g`" — fails for a different reason. For a scalar
gain channel embedded in `R` and `alpha != 0`, the kernel of
`t -> exp(2 pi i t alpha)` on any subgroup of `R` has rank at most one (two
`Q`-independent `t_1, t_2` with `t_i alpha in Z` would force
`t_1/t_2 in Q`). The rank-two module `Z[phi] g` therefore is never
annihilated by a nonzero real eigenvalue. The "index-11 after inflation
closure" arithmetic is correct finite algebra, but it does not describe any
eigenvalue constraint.

### 4. Pisot arithmetic replaces the residual-resonance problem

Solomyak's sufficiency argument uses Kenyon's realization
`Xi subset b_1 Z[theta] + ... + b_d Z[theta]` (obligation 1 is therefore also
known) and shows every `alpha in b*_1 Z[theta^{-1}] + ... + b*_d Z[theta^{-1}]`
is an eigenvalue, since `dist(theta^n P(theta), Z) -> 0` for Pisot
`theta`.[^2] For `x in Q(theta)` with `theta` a Pisot unit, `theta^n x`
approaches `Z` iff the traces `Tr(theta^n x)` are eventually integral. Hence
the finite residual test is trace integrality over the `Z[theta]`-span of
`Xi`, and an index computed from a single tail component cannot decide it
(C2 below).

### 5. `affine_forcing` is a twisted cocycle

`AffineOccurrenceEdge.forcing = q - p` enters the affine recurrence
`w' = beta w + (q - p)`, already identified as Akiyama–Lee's multiple-edge
update in `docs/p1-overlap-affine-pump-literature-gate-2026-09-15.md`.[^5]
Around a closed occurrence loop `d_0, ..., d_{k-1}`,

```text
w = beta^k w + sum_i beta^(k-1-i) d_i,
```

so the lap invariant is the `beta`-twisted sum — a class in `H^1` with
coefficients twisted by multiplication by `beta` — not `sum_i d_i`. The
upstream `finite-math-kernels` weighted cycle-gain kernel computes the plain
sum. Consequently:

- the adapter may export `affine_forcing` edge labels (it does, correctly);
- a plain-sum module of those labels is **not** the pump's loop invariant and
  must not be reported as `G_q` for this channel;
- a consumer needs either a twisted-sum channel name or a declared twist in
  the fixture before any module is computed.

The Penrose `penrose_phi_increment` channel accumulates height additively,
so the plain sum is correct there.

### 6. Penrose is a calibration, not a witness of anything new

Robinson shows the Penrose `R^2` action is strictly ergodic and an almost
1:1 extension of a minimal `R^2` rotation on `T^4`, so its pure discrete
spectrum and eigenvalue module are known.[^6] Two hypothesis boundaries
follow:

- the Penrose return module has rank 4 over `Z` (a `Z[phi]`-module of rank
  2 in `R^2`); the scalar `Z[phi]`-valued prefix height is at most a linear
  functional of it, so `Z (4 - phi)` is a rank-one shadow of a rank-four
  object;
- any "Penrose witness" can only calibrate the diagnostic against a known
  answer. Novelty claims must be restricted accordingly.

## Negative controls

Exact arithmetic in `Z[phi]`, `phi^2 = phi + 1`, `Tr(a + b phi) = 2a + b`;
checked by hand and by a throwaway exact script.

**C1 — exact annihilation is overstrong (Fibonacci).** Fibonacci tiling,
tile lengths `phi` (a) and `1` (b); return vectors between `a`-tiles include
`phi` (factor `aa`) and `phi + 1` (factor `aba`). `alpha = phi^{-1} = phi - 1`
lies in `Z[theta^{-1}]`, hence is an eigenvalue by Finding 4, yet
`(phi + 1) alpha = phi` is not an integer. An eigenvalue need not annihilate
return vectors exactly; only `theta^n z alpha -> Z` is required.

**C2 — annihilating `G_q` is not sufficient.** With `g = 4 - phi`,
`N(g) = 11`, `1/g = (3 + phi)/11`. The character `t -> exp(2 pi i t/g)` kills
`G_q = Z g` exactly. But for `z = 1` (in the `Z[phi]`-span of the Fibonacci
return vectors), `Tr(phi^n (3 + phi)) mod 11` cycles through
`7, 6, 2, 8, 10` (the order of `phi` mod 11 is 10), never `0`, so
`dist(phi^n / g, Z)` stays bounded away from zero. `alpha = 1/g` is not an
eigenvalue although it annihilates the recurrent tail's loop subgroup.
This is the concrete reason the residual mod-11 test was stopped.

**C3 — plain sum vs twisted sum.** For a two-edge loop with forcings
`d_0 = 1`, `d_1 = -1`, the plain sum is `0` while the twisted sum is
`beta - 1 != 0`. A plain-sum kernel would report a trivial gain for a loop
whose affine lap translates `w`. Any `affine_forcing` module computation
must reproduce this control before it is trusted.

## Consequences for PR #152

- The executable fixture machinery may merge as finite, exact infrastructure;
  it establishes no spectral statement.
- `docs/tier2-growth-bridge.md` obligations 3, 5, 6 are restated
  per the Decision, and its Inflation-Closure Lemma is withdrawn.
- Every fixture declares `loop_composition` (`additive` or `beta_twisted`).
  The schema pins `affine_forcing` to `beta_twisted` over the three-coordinate
  power basis, so a plain-sum reading of it is not schema-valid (Finding 5,
  C3).
- `tools/check_tier2_fixture.py` enforces the remaining semantics: gain and
  generator width = basis rank, distinct labels, power-basis rank = degree of
  the monic minimal polynomial, and `beta_twisted` only over a power basis.
