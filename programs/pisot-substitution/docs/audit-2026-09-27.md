## Executive verdict

The repository currently has **two different notions of “PSC is closed”** and they are not reconciled.

1. **Canonical mathematical status on `main`: open.** The manuscript, `claim_governance.toml`, claim map, conjecture ledger, generated proof ledger, roadmap, proof ladder and README still classify the general Pisot Substitution Conjecture as open. Seedwise overlap productivity is still an open premise of the shortest G1-free sufficiency route. The aligned strong-coincidence target remains mathematically open. The strict-zipper target remains open.
2. **Project-management premise: closed.** Issue #151 and the latest comments on #84 say the project now *treats* general PSC as closed and has moved to Tier 2. Issues #84 and #138 were manually closed on 2026-09-26.
3. **The reconciliation that would make (2) a theorem-level repository state has not happened.** Issue #153 is still open and explicitly requires the project to “document the accepted proof source and its provenance explicitly,” change the authoritative proof/status record, regenerate all derived ledgers, and then update the top-level status surfaces.

Therefore the current repository does **not** support the statement “PSC is theoremically closed on main.” What it supports is the narrower statement:

> The project has adopted a PSC-closed research premise, while the canonical theorem ledger still records PSC and the relevant completion theorems as open pending the reconciliation and accepted-proof provenance required by #153.

This is the highest-priority current-state defect. It is a status/provenance split, not a new mathematical counterexample to the existing proof architecture.

The substantive mathematical progress since the prior audit is real but narrower:

- the Barge–Štimac–Williams import underlying Theorem 5.38 has now been checked against the source;
- the strict-zipper literature gate is complete and the non-unit residual obligation has been isolated as **AdelicPeriodicOffsetHitting**;
- the full adelic prefix-difference target is specified exactly;
- a recurrent-trim Lyapunov program and an overlap-to-trim bridge have been opened as research routes;
- none of these merged results proves seedwise overlap productivity, ternary two-sided strong coincidence, AdelicPeriodicOffsetHitting, G1b-2, concentration, general wedge productivity, or the general PSC.

There is also a new source-integrity regression: three merged research notes contain literal ASCII control characters produced by mis-escaped LaTeX commands.

2. immutable provenance/digest;

Tier 2 may proceed, but it must not be presented as evidence that the general theorem was proved.

## E. Source-integrity regression in three merged research notes

The post-roadmap source audit found literal ASCII control characters in three Markdown files. These are not visual Unicode oddities; they are actual bytes/characters in the parsed GitHub content.

| File | Control characters |
| --- | ---: |
| `docs/p1b-strict-zipper-literature-gate-2026-09-21.md` | **19** |
| `docs/level3-recurrent-trim-lyapunov-2026-09-25.md` | **16** |
| `docs/p1-overlap-trim-bridge-2026-09-25.md` | **10** |
| `docs/p1b-adelic-prefix-difference-cylinder-2026-09-21.md` | **0** |

Observed control codes include backspace `0x08`, tab `0x09`, form feed `0x0C`, and carriage return `0x0D`. Their positions correspond to escaped mathematical commands such as:

- `beta`;
- `tau`;
- `rho`;
- `tag`;
- `times`;
- `frac`;
- `boxed`;
- `rangle`;
- `text`.

In other words, strings were interpreted before being written: sequences such as backslash + `b`, `t`, `r`, and `f` became control characters.

### Consequence

The mathematical prose may render incorrectly and, more importantly, copied formulas are not the formulas the notes intended to record. This is especially serious in the #139 literature gate because the file is being used as the source-transfer boundary for the non-unit branch.

### Required repair

1. rewrite those three files with literal Markdown/LaTeX backslashes or Unicode mathematical notation;
2. compare the repaired text against the intended equations;
3. add a repository regression rejecting unexpected C0 control characters in theorem/research Markdown;
4. make the check part of the source-integrity or claim-governance gate.

The clean adelic-cylinder note is a useful reference for the intended writing convention.
