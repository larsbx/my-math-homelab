# Test plan

The first executable test slice should establish:

1. projective normalization is canonical;
2. null-point enumeration agrees with known (Q^+(3,p))/(Q^-(3,p)) point counts;
3. Witt classification matches an independent discriminant criterion;
4. all anchors are tested, not one representative;
5. the tangent-parameter set from algebra agrees with singular section detection;
6. affine fiber vectors sum to (|X_p^{(0)}|);
7. split and nonsplit cases are both covered;
8. exceptional characteristics fail closed with an explicit reason.

A regression test may confirm a theorem candidate, but the claims register remains authoritative about proof status.
