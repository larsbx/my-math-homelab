# Terminology

Prefer established field language.

| Avoid | Use |
|---|---|
| closure law | identity fiber / product-one locus / multiplication fiber |
| rotation over a finite field | element of a rank-one special orthogonal group / norm-one torus element |
| complex-number rotation | quadratic étale algebra element in the norm-one subgroup |
| imaginary unit | generator of a quadratic étale algebra, when needed |
| unit circle | norm-one conic / norm-one torus |
| anisotropic circle | nonsplit rank-one torus |
| hyperbolic rotation | split rank-one orthogonal transformation |
| parabolic third regime of the torus | explicit unipotent degeneration or unipotent stabilizer |
| projective metric invariant without an absolute | projective invariant relative to a specified absolute quadric |
| Nielsen count | specify raw product-one tuples, generating tuples, Nielsen classes, or braid orbits |
| Gram analogy for trace matrix | trace-pairing Gram matrix, when literally proved |

## Style rule

Do not introduce a neologism if standard algebraic-group, Hurwitz-space, character-variety, or quadratic-form terminology already covers the object.
